# English Articles

This directory contains English translations of the Italian articles available in the main `articles/` directory.

## Available Translations

- **Cybersecurity Basics** (`cybersecurity-basics.html`) - Guide to basic cybersecurity concepts
- **Full Stack Course** (`fullstack-course.html`) - Complete guide to Full Stack development

## Structure

Each English article maintains the same structure as its Italian counterpart:
- Consistent styling and layout
- Dark/Light mode support
- Back navigation to main site
- Optimized for SEO with proper meta tags

## Adding New Translations

When adding new English translations:
1. Maintain the same filename as the Italian version
2. Update the `lang` attribute to "en"
3. Translate all meta tags and content
4. Update relative paths to point to `../../` for the main site
5. Add the article to `/sitemap.xml`

## Note

The English articles are optimized for international SEO and include:
- Proper language meta tags
- Schema.org structured data
- Optimized descriptions and keywords
